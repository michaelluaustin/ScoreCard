# **App Name**: ScoreCard+

## Core Features:

- Player Setup: Input up to 6 player names to track scores for each round.
- Course Setup: Configure the course by selecting the number of holes (9 or 18) and entering the par value for each hole.
- Round Tracker: Navigate through each hole to record player scores and track the current hole.
- Undo / Edit: Allows users to go back and edit scores for previous holes, ensuring accuracy.
- Scorecard View: Display a table with player scores for each hole, including totals and color-coding to indicate scores relative to par (over, under, or equal).
- Final Standings: Calculate and display total strokes per player and their score relative to par (+3, -1, or E).
- Share Results: Generate a shareable summary of the final results, including player names, total scores, and performance relative to par; the tool will select from different possible formats based on the players and scores involved.

## Style Guidelines:

- Primary color: A calm green (#A7D1AB) to evoke the nature of a golf course.
- Background color: A very light desaturated green (#F0F4EF).
- Accent color: A subdued blue (#85B4C4), for highlights and interactive elements.
- Body and headline font: 'PT Sans' sans-serif, providing a balance of modernity and readability suitable for both headlines and body text.
- Simple, clear icons to represent actions like adding players, setting up courses, and sharing results.
- A clean, tabular layout for the scorecard to ensure easy readability of player scores and totals.
- Subtle transitions and animations when navigating between holes and displaying scores.
